# 分析类型与任务总表

统一索引 v0.3｜2026-10-17

**共27条规格：26项分析任务 + 1项跨物种前置任务。** 其中单物种18项，跨物种分析8项。分析类型按主类别统计为8类；跨类别任务有辅助标签，不重复计数。

目前全部为研究/任务规格，尚未下载并冻结本版输入、生成数值金标准或执行科学评测。任务条数不等于独立数据集数量。

## 一、分析类型总览

| 类型 | 主要问题 | 单物种任务 | 跨物种任务 |
|---|---|---|---|
| 形态指标与相对扩张 | 提取哪些形态量？同源区域及相对面积如何不同？ | H01、M01、G01 | X01、X02 |
| 组间差异 | 实验/疾病/年龄分组之间有何形态差异？ | H02、M02 | — |
| 左右不对称 | 左右差异的方向和程度是什么？跨物种是否不同？ | H03、M03、S01、G02 | X03 |
| 形态网络 | 如何构建形态相似网络？网络组织是否保守？ | H04、M04 | X04 |
| 网络拓扑与梯度 | 模块、枢纽及主要组织梯度是什么？ | H05、H06、M05、M06 | X05 |
| 空间关联与生物学解释 | 形态或差异图与外部生物学证据如何关联？ | H07、M07、S02 | X07 |
| 多物种尺度与折叠规律 | 脑大小与面积、折叠怎样共同变化？ | — | X06 |
| 个体变异模式 | 个体差异的空间模式是否跨物种保守？ | — | X08 |

X01同时涉及物种间差异检验；X04同时涉及网络拓扑；S02同时涉及网络构建。原六类保留，新增“多物种尺度与折叠规律”和“个体变异模式”两类。

## 三、跨物种任务（1项前置 + 8项分析）

| 编号 | 分析任务 | 比较范围 | 具体工作 |
|---|---|---|---|
| X00 | 跨物种可比性与同源对应审计 | 人类—猕猴 | 建立或核验有来源的同源ROI表/表面映射；允许一对多、无对应和低置信度项。 |
| X01 | 同源脑区厚度、面积与体积比较 | 人类—猕猴 | 按同源ROI提取个体指标，分别报告原始值、相对量及适用的脑大小调整结果。 |
| X02 | 皮层相对扩张图 | 人类—猕猴 | 在已验证对应下比较局部面积占总皮层面积的比例，区分相对扩张与绝对面积差异。 |
| X03 | 左右不对称的物种差异 | 人类—猕猴 | 先物种内建立左右同源，再跨物种对应；比较AI或species×hemisphere交互。 |
| X04 | 形态网络及拓扑的保守性/差异 | 人类—猕猴 | 统一五种T1特征和共同分区，比较MIND边、节点strength、模块和枢纽。 |
| X05 | 结构协方差梯度的跨物种对应 | 人类—猕猴 | 接H06与M05，投到经验证共同空间，匹配梯度子空间，比较空间相关、区域排序及分化。 |
| X06 | 多物种脑大小与折叠异速生长 | 人类—猕猴—狨猴—大猩猩 | 计算体积/面积/折叠指标，扩充参考物种后拟合log-log及适用的系统发育模型；目标物种作为定位点。 |
| X07 | 跨物种差异图的空间关联与生物解释 | 人类—猕猴 | 将X02/X05差异图与独立皮层层级、细胞构筑、髓鞘或物种匹配表达关联。 |
| X08 | 个体差异模式的跨物种比较 | 人类—猕猴 | 比较物种内厚度/面积变异图，再比较跨物种空间模式和与扩张的关系。 |

## 四、评测集层次

- **人类主集**：H01–H07，7项。
- **猕猴主集**：M01–M07，7项。
- **跨物种主集**：X00为前置检查，X01–X05、X07–X08优先做人类—猕猴。
- **多物种扩展**：X06含人类、猕猴、狨猴、大猩猩目标物种，使用更多外部物种作为尺度分析参考。
- **少样本扩展集**：S01–S02、G01–G02，共4项。大猩猩目前是个体描述和测量验证，不用于小样本群体推断。

## 五、核心依赖与边界

1. 单物种指标/QC → 左右不对称或组间统计 → 形态网络 → 拓扑/梯度 → 生物学关联。
2. 跨物种首先通过X00，验证同源关系、尺度、图谱、采集条件可比性；同为32k不能直接逐顶点相减。
3. X01接H01/M01；X03接H03/M03；X04接H04/M04及拓扑输出；X05接H06/M05；X07使用跨物种差异图。
4. S02需要T2及狨猴表达参照，单列为条件扩展。M04是T1五特征改编，不等于原论文猕猴六特征。
5. M02原例数据可获取性未确认；统计模型、映射、原例子集和数值容差未冻结的任务不能计入正式通过率。
6. 论文中的黑猩猩比较仅是方法来源，不能被当作大猩猩数据或人类—猕猴的原样复现。
