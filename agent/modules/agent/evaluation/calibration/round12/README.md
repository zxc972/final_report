# Frozen E3 calibration baseline

Truth was frozen in frozen_cases.json and SHA-256 before any detector run. Never edit it in response to results. There are 12 historical known errors and 21 synthetic/control cases. These are AI-assisted development labels, not an independent expert blind benchmark.

The evaluator calls existing product parsers, public contract/precision checks, phase/path gates and parameterized condition templates. It neither changes rules nor calls a language-model API. Runtime-failure records are observation replays, not new code execution. Coverage-count and disclosure semantics remain not evaluated without a semantic reviewer; do not reuse the stored historical review as its answer.

Report historical and synthetic strata separately. Audit fixture-interface mismatches without editing frozen labels or tuning rules to obtain a better score. Source paths and hashes identify immutable evidence retained on the server.
