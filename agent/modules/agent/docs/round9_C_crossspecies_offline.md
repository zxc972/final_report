# Round 9 C: offline cross-species policy

C is opt-in via AGENT_CROSSSPECIES_RULES=1 for product_graph_planner only.
The paid R9 cohort remains frozen on A+B; it never used these new rules.
Original research_v13/method_graph packages and their digests are not edited.
New SHA-bound documents: cross_species_rules, species_reference_values,
conclusion_rules. They are imported into the existing SQLite knowledge layer.
Seven generic evaluators support typed species/atlas, homology, scale,
plausibility, asymmetry bias control, cross-species measure and power checks.

Species compatibility is checked per declared species/atlas binding. Unknown
identity cannot be promoted by filenames or a model declaration. SARM is
subcortical; it does not satisfy a cortical CHARM requirement. KM002 remains
monkey_unknown, so the stricter offline P1 atlas admission is not satisfied.
The requested lGI is blocked by observed software prerequisites. Its feasible
convex-hull alternative is a distinct descriptive method with no atlas demand.

Homology requires a host-verified, cited, scope-matched mapping hash. A shared
region name is never accepted. Rescale correction is metric-dependent (k,k^2,k^3);
unknown scale is a soft warning, not a positive physical-scale assertion.
Autio2020's 2.1 and reported spread0.54 are retained with the source locator, but
0.54 is not treated as a verified between-subject SD of cortical mean thickness.
All six global/hemisphere reference means are coarse plausibility anchors. A
3-SD rule runs only with a comparable SD; otherwise the project50% heuristic
is available after physical-scale and metric/scope/unit matching.
Liu2025 provides human surface-area bias evidence; applying its check to other
species is a conservative project policy. Ratios/two-species and residuals/at
least3 species are this project's registered scope policy, not universal laws.
d_min uses the supplied independent balanced-two-group normal approximation;
repeated subject IDs are deduplicated, overlapping groups are not independent,
and unequal groups use the smaller group conservatively. No t/ANCOVA/phylogenetic
power guarantee is implied. Negative underpowered results are deferred.

Agent-written success/failure criteria are required only in this opt-in mode,
along with explicit species/scale and cross-species homology references. They
are included in the hash-bound plan core and full execution bundle.
Conclusion verdict precedence and supported rewrite scope live in JSON. Cards
retain Agent prose plus typed claim scope/direction, observed checks, sources
and explicit limitations. Missing independent evidence is deferred; failed
mandatory checks are blocked. Revised typed overclaims force another conclusion
submission before a final reply. All versions remain protected. Numeric evidence
must bind the current plan hash and execution receipt. The public model has no
write access to that host observation channel.

The deterministic engine does not certify arbitrary natural-language entailment.
It does not invent normative distributions, homology data, expert QC, independent
reference ingestion, multiverse analyses or a validated biological comparison.
C tests are known synthetic regressions and metadata-only KM002 planning, not
blind validation. Real independent-reference integration remains a separate step;
without a bound independent result the card never pretends numerical acceptance.
