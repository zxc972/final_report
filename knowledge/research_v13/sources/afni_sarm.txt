<section id="overview">
<h2><a class="toc-backref" href="#id2" role="doc-backlink">Overview</a><a class="headerlink" href="#overview" title="Permalink to this heading">¶</a></h2>
<p>Here we present the Subcortical Atlas of the Rhesus Macaque
(SARM).</p>
<div class="line-block">
<div class="line">This atlas is defined in the coordinates/space of the NMT v2
template, described here:</div>
<div class="line"><a class="reference internal" href="template_nmtv2.html#nh-macaque-template-nmtv2"><span class="std std-ref">Macaque template:  NMT v2 (current)</span></a>.</div>
</div>
</section>
<section id="id1">
<h2><a class="toc-backref" href="#id3" role="doc-backlink">Contents</a><a class="headerlink" href="#id1" title="Permalink to this heading">¶</a></h2>
<p>Digitized anatomical atlases are crucial for examining brain structure
and the functional networks identified by magnetic resonance imaging
(MRI). To aid in MRI data analysis, we created a complete parcellation
of the rhesus macaque subcortex using high-resolution ex vivo structural
imaging and histological data. The structural scan was warped to the NIMH
Macaque Template (NMT v2), an in vivo population template, where the
parcellation was refined to produce the Subcortical Atlas of the Rhesus
Macaque (SARM). The NMT v2 has several forms and variants (based on
symmetry/asymmetry, FOV and voxel size), and for each of these there is
an accompanying SARM.</p>
<p>Using an updated version of the Rhesus Monkey Brain in Stereotaxic
Coordinates  (Paxinos et al., 2009; Paxinos et al., in preparation) for
guidance, the SARM features 6 parcellation levels, arranged
hierarchically from fine regions-of-interest (ROIs) to broader composite
regions, suited for fMRI studies.</p>
<p>The SARM is distributed as a single dataset with six sub-volumes. Note
that for the purpose of using AFNI sub-brick selectors, SARM Level 1 is
volume “[0]” and Level 6 is volume “[5]”, because AFNI (like Python and
C) use zero-base counting.</p>
<p>Note that the NMT v2.0 download also includes a CSV table file of the
ROI labels, hierarchically organized. This can be viewed as a simple
text file or within any spreadsheet software, such as shown in the
following image.</p>
</section>

<section id="download">
<h2><a class="toc-backref" href="#id5" role="doc-backlink">Download</a><a class="headerlink" href="#download" title="Permalink to this heading">¶</a></h2>
<p>The SARM is distributed as part of the NMT v2 download using &#64;Install_NMT
(See the instructions for the NMT installation below).</p>
<p>The SARM atlas is available only in the symmetric NMT space.</p>
<p>To download and unpack the datasets together with the NMT template and atlases,
please see these instructions...</p>
<ul class="simple">
<li><p>... here for the <strong>symmetric</strong> form:
<a class="reference internal" href="template_nmtv2.html#nh-macaque-template-nmtv2-sym-dl"><span class="std std-ref">Download symmetric NMT v2 datasets</span></a></p></li>
</ul>
<p>You may download the SARM datasets separately, from the AFNI website
using the links below.
* <em>(the plain Linux-y terminal way)</em> <strong>copy+paste</strong>:</p>
<div class="highlight-none notranslate"><div class="highlight"><pre><span></span>curl -O https://afni.nimh.nih.gov/pub/dist/atlases/macaque/SARM/SARM.tgz
tar -xvf SARM.tgz
</pre></div>
</div>
<ul>
<li><div class="line-block">
<div class="line"><em>(the mouseclick+ way)</em> <strong>click on</strong> <a class="reference external" href="https://afni.nimh.nih.gov/pub/dist/atlases/macaque/SARM/SARM.tgz">this link</a>,</div>
<div class="line">... and then unpack the zipped directory by either clicking on it
or using the above <code class="docutils literal notranslate"><span class="pre">tar</span></code> command.</div>
</div>
</li>
</ul>
</section>
<section id="afni-environment-variables">
<h2><a class="toc-backref" href="#id6" role="doc-backlink">AFNI environment variables</a><a class="headerlink" href="#afni-environment-variables" title="Permalink to this heading">¶</a></h2>
<p>The &#64;Install_NMT script automatically adds AFNI environment variables to use
the SARM atlas, but these can beThese variables can be configured in your .afnirc
file in your home directory to take advantage of the SARM atlas for “whereami”,
“Show atlas colors” and “Go to atlas location” in the AFNI GUI:</p>
<div class="line-block">
<div class="line">AFNI_SUPP_ATLAS_DIR = directory_where_you_have_installed_atlas/SARM</div>
<div class="line">AFNI_ATLAS_COLORS = SARM</div>
<div class="line">AFNI_WHEREAMI_DEC_PLACES = 2</div>
</div>
</section>
