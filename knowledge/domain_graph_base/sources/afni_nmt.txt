<section id="overview">
<h2><a class="toc-backref" href="#id2" role="doc-backlink">Overview</a><a class="headerlink" href="#overview" title="Permalink to this heading">¶</a></h2>
<p>Here we present the NIMH Macaque Template (NMT), version 2.0. This is
a group template from 31 macaques with surfaces and a 5-class tissue
segmentation.</p>
<p>The NMT v2 is the most current version of this dataset.</p>
<p>Be sure to also check out the accompanying <em>CHARM (Cortical Hierarchy
Atlas of the Rhesus Macaque)</em> dataset, described
<a class="reference internal" href="atlas_charm.html#nh-macaque-atlas-charm"><span class="std std-ref">here</span></a>.</p>
</section>
<section id="id1">
<h2><a class="toc-backref" href="#id3" role="doc-backlink">Contents</a><a class="headerlink" href="#id1" title="Permalink to this heading">¶</a></h2>
<p>There are both symmetric and asymmetric “variants” for the NMT v2.</p>
<p>Additionally, for each variant there are sets of data with different
spatial resolution and FOV:</p>
<ul class="simple">
<li><p>the “standard” NMT has 0.25 mm isotropic voxels and a
“brain-focused” FOV,</p></li>
<li><p>the “low-res” NMT has 0.5 mm isotropic voxels and a “brain-focused”
FOV,</p></li>
<li><p>the “full-head” NMT has 0.25 mm isotropic voxels and a larger FOV,
encompassing more non-brain material.</p></li>
</ul>
<p>An example of the contents in the download of the symmetric NMT v2
(which is essentially mirrored in the asymmetric version) is provided
here:</p>
<table class="docutils align-default">
<colgroup>
<col style="width: 20.0%" />
<col style="width: 80.0%" />
</colgroup>
<thead>

<th class="head"><p>Description</p></th>
</tr>
</thead>
<tbody>
<tr class="row-even"><td><p><strong>NMT_v2.0_sym/</strong></p></td>
<td><p>directory of the “standard” NMT files (i.e., standard spatial
resolution of 0.25 mm iso voxels and brain-focused FOV)</p></td>
</tr>
<tr class="row-odd"><td><p><strong>NMT_v2.0_sym_05mm/</strong></p></td>
<td><p>directory of the “low-res” NMT files (0.5 mm iso voxels; lower

analysis cases like in standard FMRI processing)</p></td>
</tr>
<tr class="row-even"><td><p><strong>NMT_v2.0_sym_fh/</strong></p></td>
<td><p>directory of the “full head” NMT files (i.e., 0.25 mm iso
voxels but a larger FOV, more non-brain material), which may be
useful for some alignment cases</p></td>
</tr>
<tr class="row-odd"><td><p><strong>NMT_v2.0_sym_surfaces/</strong></p></td>
<td><p>directory of GIFTI surfaces of many of the tissue/segmentation

<tr class="row-even"><td><p><strong>CustomAtlases.niml</strong></p></td>
<td><p>atlas description text file for AFNI</p></td>
</tr>
<tr class="row-odd"><td><p><strong>NMT_changelog.txt</strong></p></td>
<td><p>text file of changes and updates to the distributed datasets</p></td>
</tr>
<tr class="row-even"><td><p><strong>NMT_v2.0_sym_env.csh</strong></p></td>
<td><p>script to set AFNI environment variables for AFNI to use
atlases and make AFNI more monkey friendly.  <strong>Note:</strong> running
this script will change your default atlases for <code class="docutils literal notranslate"><span class="pre">whereami</span></code>
functionality, so if you also do human studies, be aware that
you might have to change some environment settings again later.</p></td>
</tr>
<tr class="row-odd"><td><p><strong>supplemental_CHARM/</strong></p></td>
<td><p>directory of tables of CHARM ROI index/label definitions and more</p></td>
</tr>
<tr class="row-even"><td><p><strong>supplemental_D99/</strong></p></td>
<td><p>directory of a table of D99 ROI index/label definitions</p></td>
</tr>
</tbody>
</table>

<section id="download-symmetric-nmt-v2-datasets">
<span id="nh-macaque-template-nmtv2-sym-dl"></span><h2><a class="toc-backref" href="#id5" role="doc-backlink">Download symmetric NMT v2 datasets</a><a class="headerlink" href="#download-symmetric-nmt-v2-datasets" title="Permalink to this heading">¶</a></h2>
<p>You can download and unpack the <strong>symmetric variant/form</strong> of the NMT
v2 in any of the following ways:</p>
<ul>
<li><p><em>(the AFNI way)</em> <strong>copy+paste</strong>:</p>
<div class="highlight-none notranslate"><div class="highlight"><pre><span></span>@Install_NMT -nmt_ver 2.0 -sym sym
</pre></div>
</div>
</li>
<li><p><em>(the plain Linux-y terminal way)</em> <strong>copy+paste</strong>:</p>
<div class="highlight-none notranslate"><div class="highlight"><pre><span></span>curl -O https://afni.nimh.nih.gov/pub/dist/atlases/macaque/nmt/NMT_v2.0_sym.tgz
tar -xvf NMT_v2.0_sym.tgz
</pre></div>
</div>
</li>
<li><div class="line-block">
<div class="line"><em>(the mouseclick+ way)</em> <strong>click on</strong> <a class="reference external" href="https://afni.nimh.nih.gov/pub/dist/atlases/macaque/nmt/NMT_v2.0_sym.tgz">this link</a>,</div>
<div class="line">... and then unpack the zipped directory by either clicking on it
or using the above <code class="docutils literal notranslate"><span class="pre">tar</span></code> command.</div>
</div>
</li>
</ul>
</section>
<section id="download-asymmetric-nmt-v2-datasets">
<span id="nh-macaque-template-nmtv2-asym-dl"></span><h2><a class="toc-backref" href="#id6" role="doc-backlink">Download asymmetric NMT v2 datasets</a><a class="headerlink" href="#download-asymmetric-nmt-v2-datasets" title="Permalink to this heading">¶</a></h2>
<p>You can download and unpack the <strong>asymmetric variant/form</strong> of the NMT
v2 in any of the following ways:</p>
<ul>
<li><p><em>(the AFNI way)</em> <strong>copy+paste</strong>:</p>
<div class="highlight-none notranslate"><div class="highlight"><pre><span></span>@Install_NMT -nmt_ver 2.0 -sym asym
</pre></div>
</div>
</li>
<li><p><em>(the Linux-y terminal way)</em> <strong>copy+paste</strong>:</p>
<div class="highlight-none notranslate"><div class="highlight"><pre><span></span>curl -O https://afni.nimh.nih.gov/pub/dist/atlases/macaque/nmt/NMT_v2.0_asym.tgz
tar -xvf NMT_v2.0_asym.tgz
</pre></div>
</div>
</li>
<li><div class="line-block">
<div class="line"><em>(the mouseclick+ way)</em> <strong>click on</strong> <a class="reference external" href="https://afni.nimh.nih.gov/pub/dist/atlases/macaque/nmt/NMT_v2.0_asym.tgz">this link</a>,</div>
<div class="line">... and then unpack the zipped directory by either clicking on it
or using the above <code class="docutils literal notranslate"><span class="pre">tar</span></code> command.</div>
</div>
</li>
</ul>
</section>
